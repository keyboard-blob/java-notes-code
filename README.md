## 约定

- 每个目录是一份可直接编译运行的最小工程，源码按包名放在 `src/` 下
- 只用 JDK 标准库，没有外部依赖
- 源码是 UTF-8，编译时记得加 `-encoding UTF-8`
- 每份工程目录里都有 README，写了编译命令和入口类
